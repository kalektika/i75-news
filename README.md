# i75-news

`news.json` for the Interstate 75W desk display. Written by a scheduled Claude routine, read by the board.

Schema: `{"v":1,"gen":"ISO UTC","items":[{"k":"MU","c":"n|u|e","i":1-3,"t":"ISO UTC","x":"text with *highlight*"}]}`
`c`: n = news (t = published), u = token unlock, e = earnings (t = event time).
